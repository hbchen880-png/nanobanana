这个包是完整的 Windows 打包包。

已包含：
- runninghub_image_generator_gui.py
- build_exe.bat
- NanoBananaImageGenerator.spec
- requirements.txt
- build_installer.bat
- installer.iss

使用方法：
1. 在 Windows 上解压
2. 双击 build_exe.bat 生成 dist\NanoBananaImageGenerator.exe
3. 如需安装包，先安装 Inno Setup 6，再双击 build_installer.bat
4. 生成 installer_dist\NanoBananaImageGenerator_Setup.exe
